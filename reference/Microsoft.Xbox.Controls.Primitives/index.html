DepthPIP¶

class Microsoft.Xbox.Controls.Primitives.DepthPIP

Shows the Kinect camera feed in a small picture-in-picture rectangle so users can see how the sensor sees them.

The template part NuiCameraRectangle (a Rectangle) is filled with a video brush whose source is the Kinect camera. The control is visible only while it is enabled and the Kinect sensor reports that it is ready; it collapses itself otherwise. Used by Feedback.

NuiTimelinePanel¶

class Microsoft.Xbox.Controls.Primitives.NuiTimelinePanel

A panel that positions NuiTimelineMarker children horizontally by time, using the enclosing NuiTimeline to convert times to pixels.

The panel finds the nearest NuiTimeline ancestor on first arrange and binds NuiTimelinePanel.TimelineStartPosition and NuiTimelinePanel.TimelineEndPosition to it. Markers are arranged at their start time with their desired width and the panel height, and NuiTimelineMarker.DurationWidth is set. Markers that extend past the timeline are collapsed (or trimmed if NuiTimelineMarker.IsClamped). Other children fill the panel. The panel reports a desired size of zero.

ResolutionNormalizingPanel¶

class Microsoft.Xbox.Controls.Primitives.ResolutionNormalizingPanel

A panel that lays out its children at a fixed logical height and scales them to the panel's actual size, so content designed for one resolution looks the same at 720p and 1080p.

Children are measured and arranged at ResolutionNormalizingPanel.NormalizedHeight by a width that keeps the panel's aspect ratio, and then given a ScaleTransform equal to the actual height divided by the normalized height. This replaces any non-scale RenderTransform on the children. With unconstrained available size, the panel sizes itself to the screen width and to the normalized height scaled from a 720-line reference.

TipsManager¶

class Microsoft.Xbox.Controls.Primitives.TipsManager

Shows Kinect tips and the wave-to-engage progress in the Feedback strip.

While loaded, the control listens to the Kinect sensor: it shows a warming-up tip while the sensor starts, an identifying tip and a welcome message (with the user's gamertag when known) when a user engages, and the left- or right-hand wave progress. If the VuiBar is enabled and recognizing, a voice tip is shown every 30 seconds. Most tips fade after 10 seconds.

Visual state groups: VisualTipStates (EmptyTip, WaveTip, WelcomeTip, VuiTip, IdentifyingTip, KinectWarmingUpTip) and WaveStates (NoWave, LeftWave, RightWave). The text properties are set by the control from its localized strings and are refreshed when Localization.Culture changes, so values you assign may be overwritten.

VirtualizingGrid¶

class Microsoft.Xbox.Controls.Primitives.VirtualizingGrid

The paging items panel of ContinuousList. It places item containers into a Grid column by column and only keeps the columns around the visible page realized.

Use it only as the items panel of a ContinuousList; it reports paging and visible items back to that list. Items fill the grid's rows top to bottom, then move to the next column. Page changes animate with a 0.5-second ease-out slide. Directional focus moves between the realized items; moving focus past the edge of the page pages the list.

VuiMeter¶

class Microsoft.Xbox.Controls.Primitives.VuiMeter

The animated microphone level meter on the VuiBar.

Each Rectangle in the template part RectangleParent is scaled vertically to random heights. While the voice bar is visible the heights are drawn from the active range when speech sound is detected and from the inactive range otherwise; when the bar hides the bars settle to VuiMeter.InactiveMin. Each animation lasts a base time plus a scale time multiplied by the target height. The meter requires VuiBar.Current.
