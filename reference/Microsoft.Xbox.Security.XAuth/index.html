XAuthCompletedEventArgs¶

class Microsoft.Xbox.Security.XAuth.XAuthCompletedEventArgs

Provides data for the XAuthTokenRequest.Completed event.

Check AsyncCompletedEventArgs.Error first; when it is not null it is an XAuthException and XAuthCompletedEventArgs.Token is null. The UserState property contains the request's XAuthTokenRequest.UserData.

Properties
Microsoft.Xbox.Security.XAuth.XAuthToken Token { get; } Gets the token that was obtained.

XAuthException¶

class Microsoft.Xbox.Security.XAuth.XAuthException

The exception that is thrown when an Xbox LIVE token (XAuth) operation fails.

The Exception.HResult property holds the failure code returned by the platform, and the message names the operation that failed together with that code in hexadecimal.

XAuthToken¶

class Microsoft.Xbox.Security.XAuth.XAuthToken

Represents an Xbox LIVE security token issued for a signed-in user and a relying party (web service).

Tokens are obtained through XAuthTokenRequest and cached by XAuthService. Two tokens are considered equal when they belong to the same user and the same relying party; the token bytes are not compared.

XAuthTokenRequest¶

class Microsoft.Xbox.Security.XAuth.XAuthTokenRequest

Requests an Xbox LIVE security token for a signed-in player and a web service URN, either synchronously or asynchronously.

A request object can be used for one token request only; calling a Get method a second time throws ArgumentException. The user must be signed in to Xbox LIVE and the URN must be one the title is allowed to request tokens for (see XAuthService.LoadWhiteList). Call XAuthService.Start before requesting tokens.

Constructors
XAuthTokenRequest()

Properties
System.Object UserData { get; set; } Gets or sets an application-defined object that is returned in the completion event arguments.

Methods
Microsoft.Xbox.Security.XAuth.XAuthToken GetToken(System.Int32 playerIndex, System.Uri urn) Obtains a token synchronously for the specified player and URN. This call blocks until the service responds, so avoid it on the UI thread. It throws ArgumentException if urn is null, if the request object was already used, or if a XAuthTokenRequest.Completed handler is attached (use GetTokenAsync in that case). Platform failures are reported as XAuthException.
System.Void GetTokenAsync(System.Int32 playerIndex, System.Uri urn) Starts an asynchronous request for a token for the specified player and URN. The result is delivered through XAuthTokenRequest.Completed. A token already in the cache is delivered immediately; requests made before the token service is ready are queued until it is. Throws ArgumentException if this request object was already used.

Fields
System.EventHandler<Microsoft.Xbox.Security.XAuth.XAuthCompletedEventArgs> Completed Occurs when an asynchronous token request finishes, successfully or not. This is a public delegate field rather than an event; assign or combine handlers before calling XAuthTokenRequest.GetTokenAsync. If the token is already cached, the handler runs before GetTokenAsync returns. Otherwise it runs later, possibly on a thread other than the UI thread, so marshal UI updates through the Dispatcher. The sender argument is null.

XAuthXuid¶

class Microsoft.Xbox.Security.XAuth.XAuthXuid

Represents the Xbox user ID (XUID) of the gamer an Xbox LIVE token was issued for.

Instances are created by the platform and returned from XAuthToken.UserId. Convert to Int64 to read the numeric XUID.

Operators
static System.Int64 op_Implicit(Microsoft.Xbox.Security.XAuth.XAuthXuid x) Converts an XAuthXuid to its 64-bit numeric XUID.
