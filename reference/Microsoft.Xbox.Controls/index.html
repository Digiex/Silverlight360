ContinuousList¶

class Microsoft.Xbox.Controls.ContinuousList

A horizontally paged list for the 10-foot UI. Items are laid out in columns and the user pages left and right with the shoulder buttons, the D-pad, the remote's previous/next keys or a Kinect swipe.

Items are wrapped in ContinuousListItem containers and arranged by a VirtualizingGrid items panel (the default template). The number of rows comes from the row definitions of the panel's VirtualizingGrid.Grid; columns are created as needed.

The template contains a SwipeViewer named SwipeElement, so the list responds to Kinect swipes. Only one SwipeViewer can be active at a time, so do not show two swipe-enabled controls (for example a ContinuousList and a Pivot) on the same page.

Raises ItemsInViewChanged whenever the set of fully visible items changes. During page transitions in an XboxApplicationFrame the item area is clipped to the screen.

MediaTransport has built-in adapters for MediaElement and the Smooth Streaming SmoothStreamingMediaElement. Legend¶

class Microsoft.Xbox.Controls.Legend

Shows the controller button legend (A, B, X, Y and their meanings) for the element that currently has focus.

Set the attached properties (AButtonText, BButtonText, XButtonText, YButtonText) on a control. When focus moves, the legend walks up the visual tree from the focused element and, for each button, uses the text from the nearest supported ancestor that defines it. Buttons with no text (or an empty string) are hidden.

The attached properties can only be set on a Button, Pivot, ContinuousList, XboxApplicationFrame, Rune or NuiScrollViewer (or a subclass); setting them on any other type throws InvalidOperationException.

The legend is visible only while the current input modality is the controller and the control is enabled; it collapses itself when the user switches to Kinect gestures. It is normally used through Feedback.

Localization¶

class Microsoft.Xbox.Controls.Localization

Holds the culture used by the Xbox controls for their built-in strings and speech language, and exposes the console's language and locale settings.

At startup the culture is chosen from the engaged user's profile if one is available, otherwise from the console language and locale settings. Controls such as MediaTransport, Rune, VuiBar and the tips shown by Feedback refresh their text when the culture changes. The XC_LANGUAGE_* and XC_LOCALE_* constants are the values returned by Localization.GetConsoleLanguage and Localization.GetConsoleLocale.

Properties
static System.Globalization.CultureInfo Culture { get; set; } Gets or sets the culture the Xbox controls use for their own text and for speech recognition. Setting a new culture updates the controls' resource strings and raises Localization.CultureChanged. If a VuiBar exists, it stops recognition, switches the speech language (when the culture is supported) and unloads every loaded VuiGrammar, including ones loaded by the app; reload your grammars and call VuiBar.StartRecognition again after the change.

MediaTransport¶

class Microsoft.Xbox.Controls.MediaTransport

Full-screen video playback chrome for Xbox: an overlay with a NUI timeline, a controller transport bar, status text, a busy indicator and an optional custom control panel, wired to a media player.

Put a MediaElement, a Smooth Streaming SmoothStreamingMediaElement or your own IMediaElementAdapter in Content (it is assigned to MediaTransport.MediaElement automatically), or set MediaTransport.MediaElement directly. While loaded, the transport polls the player every 100 ms and updates MediaTransport.Position, MediaTransport.Duration, the seekable range, MediaTransport.PlayRate, MediaTransport.IsBusy and the automatic button states.

Input: A, Start, Enter or the D-pad show the transport bar with focus on Play/Pause; the triggers rewind and fast forward; the shoulder buttons skip to the previous/next chapter marker; B hides the bar, panel or overlay, and raises MediaTransport.Back when nothing is left to hide; the Back button always raises MediaTransport.Back. Remote media keys are routed through MediaTransport.ExecuteMediaCommand. With Kinect, an engaged user sees the overlay and can scrub the timeline with the hand gesture handled by NuiTimeline.

Fast forward and rewind are emulated: the player is paused and the timeline position advances at the selected PlayRate; the player is seeked to the previewed position when the user plays or pauses.

Side effects while loaded and enabled: the console is told that video is playing (native ordinal 602) so the dashboard treats the app as a media app; the media state (position, duration, rate, capabilities and MediaTransport.MediaAssetId) is reported for companion devices (native ordinal 600); the screen saver is suppressed during playback when MediaTransport.IsScreenSaverAutoDisabled is set (requires GamerServices to be initialized, which XboxApplicationFrame does); and play, pause, stop, skip and scrub actions are reported to the media usage service.

Important: the usage reporting requires MediaTransport.MediaAssetId. Play, Pause, Stop, skip, scrubbing, Back and rate changes throw InvalidOperationException if it is null or empty, so set it before playback starts.

NuiTimeline¶

class Microsoft.Xbox.Controls.NuiTimeline

The media timeline used by MediaTransport: a progress bar with markers, position text, a preview thumbnail and a Kinect "gearshift" handle for scrubbing.

While loaded, the timeline creates a native scrub tracker (npctrl.dll ordinals 500–510) that follows the engaged Kinect user's hand on the gearshift handle. Dragging the handle zooms the timeline in, moves NuiTimeline.Position, snaps to snappable markers once the user commits, and raises NuiTimeline.ScrubbingStarted, NuiTimeline.Scrubbing and NuiTimeline.ScrubbingCompleted. Scrubbing only happens while NuiTimeline.IsScrubbingEnabled is true, so it needs a Kinect sensor and an engaged user.

Template parts: TimelineBarPanel (Panel), TimelinePositionPanel (Panel) and Gearshift (NuiGearshift). Visual state groups: ZoomStates (ZoomedIn/ZoomedOut), ThumbnailVisibilityStates and GearshiftVisibiltyStates.

The many read-only Interpolated…, …Offset… and …Width properties are layout values computed for the template; apps normally only set the position range, NuiTimeline.Markers and the content properties.

VuiBar¶

class Microsoft.Xbox.Controls.VuiBar

The voice user interface (VUI) bar: Kinect speech recognition for the app and the on-screen bar that lists the commands the user can say.

Only one instance can exist; it is available as VuiBar.Current. The default XboxApplicationFrame template already contains it, so apps normally do not create one. Creating a second instance throws InvalidOperationException.

Typical setup: create one or more VuiGrammar objects with phrases whose semantic values match your commands' VuiCommand.SemanticValue, call VuiBar.LoadGrammar for each, add VuiCommand objects to VuiBar.PrimaryCommands or VuiBar.SecondaryCommands, and call VuiBar.StartRecognition. Grammars can only be loaded or unloaded while recognition is stopped. The phrases for the built-in VuiCommands are loaded automatically.

The user says "Xbox" to open the bar (active listening, which times out after 12 seconds without a command). While the bar is open the user can say a command phrase on its own; while it is closed, a command can be said together with the "Xbox" keyword. The two cases use separate confidence thresholds. If a phrase matches several executable commands the bar enters disambiguation and labels the candidates (see VuiBar.SetDisambiguationSlots). Commands with a VuiCommand.Confirmation ask for confirmation before running. Two fixed commands, Cancel and go Home (with an explicit confirmation), are always available while the bar is open.

Speech requires a Kinect sensor, a supported Localization.Culture and speech recognition being enabled in the console settings; check VuiBar.IsCurrentCultureSupported and VuiBar.IsDashSpeechRecognitionEnabled. Changing Localization.Culture stops recognition and unloads all grammars, including the app's.

Events and command execution happen on the UI thread. Native calls go to npctrl.dll ordinals 200–218 and 1200.

VuiCommand¶

class Microsoft.Xbox.Controls.VuiCommand

A command the user can trigger by voice through the VuiBar.

A command is matched to speech through its VuiCommand.SemanticValue: load a VuiGrammar containing one or more phrases with that semantic value, then add the command to VuiBar.PrimaryCommands or VuiBar.SecondaryCommands (or assign it to PivotItem.VuiCommand). When recognized, the command runs VuiCommand.TargetCommand and raises VuiCommand.Executed.

The command is an ICommand, so it can also be bound to buttons. A command can be attached to only one loaded UI element at a time; doing otherwise throws InvalidOperationException.

The predefined commands in VuiCommands are built in: their display text, semantic value and confirmation settings cannot be changed.

XboxApplicationFrame¶

class Microsoft.Xbox.Controls.XboxApplicationFrame

The navigation frame to use as the root of an Xbox Silverlight app. It hosts pages, plays page transitions and contains the app's VuiBar.

Creating the frame initializes GamerServices (GamerServicesDispatcher.Initialize) and the UI sound system if they are not initialized yet, and pumps the XNA framework and GamerServices dispatchers on every rendered frame. Controls that depend on GamerServices, such as the screen-saver handling in MediaTransport, therefore work automatically inside this frame.

The template must contain a VuiBar named PART_VuiBar (the default template does); otherwise InvalidOperationException is thrown. Only one VuiBar may exist per app, so do not add another one when you use this frame.

On navigation the old and new pages are shown in two presenters and their navigation transitions (set with the TransitionService attached properties) are played. Elements marked as transition targets animate in order after the page. Any SwipeViewer on the outgoing page is turned off and the one on the incoming page is turned on.
