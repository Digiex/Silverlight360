PRNDReceiver¶

class System.Windows.Media.PRNDReceiver

A PlayReady-ND (network device) receiver: obtains licenses for protected content from a PlayReady-ND transmitter on the local network.

Call PRNDReceiver.OpenAsync, then PRNDReceiver.PerformHandshakeAsync, then PRNDReceiver.AcquireLicenseAsync for each item; wait for each step's completion event before the next. Pass PRNDReceiver.SessionId to the media pipeline with MediaSourceAttributesKeys.PRNDSessionID.

Exceptions thrown by your event handlers are swallowed.

Constructors
PRNDReceiver()

Properties
System.Byte[] SessionId { get; } Gets the identifier of the receiver's current session.
System.Int32 HandshakeAlertInterval { get; set; } Gets or sets how long after a successful handshake PRNDReceiver.PRNDReceiverHandshakeAlert is raised, in minutes. Set it before the handshake; the timer is started when the handshake completes.

Methods
System.Void AcquireLicenseAsync(System.Windows.Media.ContentIdentifierType contentIdentifierType, System.Byte[] contentIdentifier, System.Byte[] customDataTypeId, System.Byte[] customData) Starts acquiring a license for one content item from the transmitter. Completion is reported by PRNDReceiver.PRNDReceiverAcquireLicenseCompleted.
System.Void Close() Closes the receiver and cancels any pending handshake alert. The receiver can then be opened again.
System.Void OpenAsync(System.Uri transmitterUri) Starts connecting to a PlayReady-ND transmitter. Completion is reported by PRNDReceiver.PRNDReceiverOpenCompleted.
System.Void PerformHandshakeAsync(System.Byte[] customDataTypeId, System.Byte[] customData) Starts the registration handshake with the transmitter, optionally sending custom data. Completion is reported by PRNDReceiver.PRNDReceiverPerformHandshakeCompleted. The handshake may be repeated on an open receiver.

Events
event System.EventHandler PRNDReceiverHandshakeAlert Occurs once, PRNDReceiver.HandshakeAlertInterval minutes after a successful handshake, to signal that the handshake (proximity check) should be repeated. Raised on the UI thread by a dispatcher timer. The event arguments are null. PRNDReceiver.Close cancels the pending alert.
event System.EventHandler<System.Windows.Media.PRNDReceiverAcquireLicenseCompletedEventArgs> PRNDReceiverAcquireLicenseCompleted Occurs when PRNDReceiver.AcquireLicenseAsync finishes.
event System.EventHandler<System.Windows.Media.PRNDReceiverOpenCompletedEventArgs> PRNDReceiverOpenCompleted Occurs when PRNDReceiver.OpenAsync finishes. If AsyncCompletedEventArgs.Error is null the receiver is open and ready for a handshake; otherwise it holds a PRNDException.
event System.EventHandler<System.Windows.Media.PRNDReceiverPerformHandshakeCompletedEventArgs> PRNDReceiverPerformHandshakeCompleted Occurs when PRNDReceiver.PerformHandshakeAsync finishes. On success the receiver can acquire licenses, and the timer for PRNDReceiver.PRNDReceiverHandshakeAlert starts.

Fields
const System.Int32 IdByteCount The length, in bytes, of session IDs and custom data type IDs (16). This field is constant.
const System.Int32 MaxHandshakeAlertInterval The largest value accepted by PRNDReceiver.HandshakeAlertInterval: 2880 minutes (48 hours). This field is constant.
