MediaUsageServiceClient¶

class Microsoft.Xbox.Services.MediaUsageServiceClient

Reports playback activity (play, pause, stop and so on) for media items to the Xbox LIVE media usage service.

Nothing is sent until MediaUsageServiceClient.UploadUsageEnabled is set to true. Events are queued (up to about 1,000) and posted in batches every 2 seconds by a UI-thread timer, using the Xbox LIVE token of the user at player index 0. Create the client on the UI thread.

Constructors
MediaUsageServiceClient()

Properties
System.Boolean UploadUsageEnabled { get; set; } Gets or sets whether usage events are collected and uploaded. The default is false; while it is false, MediaUsageServiceClient.UploadMediaUsageAsync discards events.
static System.String SignalsMediaServiceBaseUrl { get; } Gets the base URL of the media usage service for the environment the console is configured for, derived from NetworkSettings.ActiveServiceEndpoint the first time it is read.

Methods
System.Void UploadMediaUsageAsync(System.String mediaAssetId, Microsoft.Xbox.Services.UsageEventType eventType, Microsoft.Xbox.Services.MediaType mediaType, System.TimeSpan timelineEventTime, System.TimeSpan mediaLength) Queues a playback event for upload. The event is timestamped with the current UTC time and sent with the next batch. Does nothing if MediaUsageServiceClient.UploadUsageEnabled is false.

Events
event System.EventHandler<Microsoft.Xbox.Services.UploadMediaUsageCompletedEventArgs> UploadMediaUsageCompleted Occurs after a batch of usage events has been posted, or when queuing or posting fails. Check AsyncCompletedEventArgs.Error.

RatingsServiceClient¶

class Microsoft.Xbox.Services.RatingsServiceClient

Reads and writes media ratings and reviews on the Xbox LIVE ratings service for a signed-in user.

Each call first resolves the service URL from the Xbox LIVE service directory (cached until it expires), then sends an HTTP request authorized with the user's Xbox LIVE token. Results arrive through the matching ...Completed event; check AsyncCompletedEventArgs.Error before reading Result. Exceptions during the operation are reported through the event rather than thrown.

If the service directory has no entry for the operation, the event is raised with no error and a null Result.

Constructors
RatingsServiceClient(System.Int32 playerIndex) Creates a ratings client that acts on behalf of the specified user.

Methods
System.Void DeleteUserRatingAsync(System.String mediaAssetId) Starts deleting the user's rating of a media item. Completion is reported by RatingsServiceClient.DeleteUserRatingCompleted.
System.Void DownloadAggregateRatingsAsync(System.String mediaAssetId) Starts downloading the community rating of a media item. The result is reported by RatingsServiceClient.DownloadAggregateRatingsCompleted.
System.Void DownloadUserRatingAsync(System.String mediaAssetId) Starts downloading the user's own rating of a media item. The result is reported by RatingsServiceClient.DownloadUserRatingCompleted.
System.Void UploadUserRatingAsync(System.String mediaAssetId, System.Double ratingValue, System.String reviewText) Starts saving the user's rating and optional review of a media item. Completion is reported by RatingsServiceClient.UploadUserRatingCompleted.
System.Void UploadUserRatingAsync(System.String mediaAssetId, System.Double ratingValue, System.String reviewText, Microsoft.Xbox.Services.UserInterest userInterest) Starts saving the user's rating, optional review and interest for a media item. Completion is reported by RatingsServiceClient.UploadUserRatingCompleted.
System.Void UploadUserRatingInterestAsync(System.String mediaAssetId, Microsoft.Xbox.Services.UserInterest userInterest) Starts saving only the user's interest in a media item, without a rating value. Completion is reported by RatingsServiceClient.UploadUserRatingCompleted.

Events
event System.EventHandler<Microsoft.Xbox.Services.DeleteUserRatingCompletedEventArgs> DeleteUserRatingCompleted Occurs when RatingsServiceClient.DeleteUserRatingAsync finishes. Once the request has been sent, this event reports success even if the HTTP request failed; only errors while resolving the service URL are reported in AsyncCompletedEventArgs.Error.
event System.EventHandler<Microsoft.Xbox.Services.DownloadAggregateRatingsCompletedEventArgs> DownloadAggregateRatingsCompleted Occurs when RatingsServiceClient.DownloadAggregateRatingsAsync finishes.
event System.EventHandler<Microsoft.Xbox.Services.DownloadUserRatingCompletedEventArgs> DownloadUserRatingCompleted Occurs when RatingsServiceClient.DownloadUserRatingAsync finishes.
event System.EventHandler<Microsoft.Xbox.Services.UploadUserRatingCompletedEventArgs> UploadUserRatingCompleted Occurs when an upload started with UploadUserRatingAsync or RatingsServiceClient.UploadUserRatingInterestAsync finishes. On success, Result holds the rating as stored by the service.

UsageEventType¶

enum Microsoft.Xbox.Services.UsageEventType

Playback actions reported with MediaUsageServiceClient.UploadMediaUsageAsync.

Values
End Playback reached the end of the item.
Forward The user fast-forwarded.
Pause Playback was paused.
Play Playback started.
Resume Playback resumed after a pause.
Rewind The user rewound.
Skip The user skipped to another position or item.
Stop The user stopped playback before the end.
