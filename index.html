Silverlight360 documentation¶

Silverlight360 builds C# and XAML Silverlight apps for the Xbox 360 Silverlight platform, the one Netflix, YouTube and the other Xbox 360 apps used. The output is a package with a default.xex you can run in the xenia-edge emulator.

The code, samples and tools are at github.com/Digiex/Silverlight360.

Guides:
Getting started Install the tools, make a runtime profile, build and run a sample.
Projects and Visual Studio The project file, references, build properties, packaging, IntelliSense.
App model Startup, XboxApplicationFrame, pages and navigation, back and exit, the TV screen.
Input and focus Controller events, focus, moving focus with the D-pad, the Legend, media remotes.
Xbox controls Pivot, Rune, Legend, MediaTransport, ContinuousList, transitions, speech.
Networking WebClient and HttpWebRequest, cross-domain policy, what needs Xbox LIVE.
Storage Saving settings in a storage container, the cache drive.
Media MediaElement, MediaTransport, Smooth Streaming, DRM.
Gamer services Signed-in gamers, the Guide, presence, threading.
Native code Calling the kernel and XAM with DllImport.
Testing in xenia Running an app with scripted controller input and screenshots.
Status under xenia What works in the emulator today and what doesn't.

Reference:

  • API reference: the Xbox libraries and the Xbox additions to Silverlight, one page per namespace. The same text appears in Visual Studio's IntelliSense.
  • Samples: what each sample shows and how it was tested.
  • Runtime inventory: the platform versions found in the shipped apps.

Everything here comes from running apps in the xenia-edge emulator and from reading the platform's own assemblies. Of the samples, only PageNavigation has been run on a console so far.
